- Selecting text no longer puts the whole app on the processor to draw, so holding something down stops turning everything sluggish
- The composer stops shrinking under you the moment you select something in the chat
- Reading back through a chat no longer shakes line by line while an answer arrives
- An image or a PDF is fetched once instead of on every redraw, and zooming one that is still loading no longer cancels it
- Holding a link in the chat opens its menu instead of dragging the link away
- Holding an item inside a menu no longer closes the keyboard behind it
- A tooltip opened by holding a button closes with whatever you do next
- Back closes the menu or dialog you have open and nothing else, instead of also leaving the screen behind it
- An account whose provider is off says the model is unavailable instead of listing models it cannot run
- Switching to an external provider only shows the model chip loading, and sending waits until there is a model to send to
- Interrupting an answer with a message already queued keeps the message
- Coming back from Files or Settings no longer flashes the press effect, notes are written at the file viewer size, the side panel can be resized with a preview open, and dragging text no longer raises the file drop overlay
